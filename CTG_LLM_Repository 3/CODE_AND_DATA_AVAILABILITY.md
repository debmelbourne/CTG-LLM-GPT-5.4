# Code and data availability

We release the public analysis software, reference prompts and response schemas, deterministic parsing and category mappings, an Azure inference interface, CTU rendering code, secondary predictor preparation and partitioning, probability-evaluation functions, and model-combination documentation and pseudocode under the software licence included in this repository.

No participant-level dataset, simulated dataset, CTG image, raw model response, fitted model or aggregate results table is distributed. The article and Supplementary Information report the study results.

Qualified researchers may request the de-identified study images, linked clinical variables and outcome labels needed for verification from Debjyoti Karmakar (debmelbourne@gmail.com) and Fiona Brownfoot (fionabrownfoot@gmail.com). Requests specify the research purpose, required data and proposed analyses. Access depends on approval by the relevant Mercy Health data custodian and the University of Melbourne, any necessary ethics approval, and an appropriate data-sharing or transfer agreement.

The underlying CTU-UHB Intrapartum Cardiotocography Database, version 1.0.0, is independently available in raw form from [PhysioNet](https://doi.org/10.13026/C22013) under its repository terms. Study-specific renderings, eligibility decisions, derived labels and linked analysis inputs are covered by the request process above.

The complete study implementation includes protected components for model integration, feature extraction, preprocessing, deployment and model combination. Further implementation details and retained study inference records can be requested from the corresponding authors for verification or replication, subject to University approval, applicable governance and journal requirements, and an appropriate confidentiality or licensing agreement. The public reference implementation is not an export of the institutional deployment.

Guideline publications remain subject to their respective rights holders' terms. The references identify the editions used; the publications themselves are not redistributed.
