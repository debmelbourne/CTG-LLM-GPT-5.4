# Public package verification

Verified 11 November 2026 with Python 3.12.14 and the package versions recorded in `environment/requirements-verified.txt`. All selected dependency releases were published by 31 October 2026, as recorded in `environment/software_versions.json`.

All 41 public checks passed: 26 contract checks, four rendering checks and 11 secondary-analysis checks. The contract checks cover all 18 raw-category values, the Supplementary Table S1 mappings, strict parsing, missing and invalid responses, schema validity, independent request construction, retry limits, refusal handling, model-version checks and resume configuration. Service calls use the installed OpenAI SDK with an in-memory HTTP transport; no Azure model requests are made by the checks. The rendering checks cover the time axis, range and abrupt-change masks, preservation of missing FHR intervals, and settings and output-name validation. Secondary checks cover predictor transformations, missingness, partition separation and reproducibility, probability metrics, paired comparisons and invalid-input handling.

Additional release checks verified the statistical kernels and cohort rules against the study scripts, exercised all five analysis interfaces, validated all seven JSON schemas, and checked the installed package resources. The complete six-request workflow was exercised with a mocked service, including a failed quality response followed by all five classification requests, resumption of completed requests, changed-image rejection and conversion of the audit into category columns. No test records or test outputs are distributed as datasets.

The retained rendering functions match the earlier public source byte for byte. The rendering command differs only in its package import path. Additional checks confirmed equivalent WFDB and CSV image output, valid rendering manifests, fixed output dimensions and independence from clinical header comments. They also verified the distinction between preserved FHR gaps and limited interpolation of missing TOCO samples.

Source comparisons confirmed equivalent predictor preparation, identical four-way partition assignments, held-out and external probability metrics, and paired AUROC-difference calculations. Both secondary preparation modes, both probability-evaluation modes and all five category-analysis modes were exercised through the public interfaces. The public preparation and evaluation functions shared by the two secondary source scripts were also compared directly.

The package built and installed successfully. The public test entry point is `python -m unittest discover -s tests -v` with the inference, rendering and evaluation dependency groups installed. Verification is of the public software interfaces and calculations; it does not establish repeat-inference performance or independently reproduce the protected secondary models.
